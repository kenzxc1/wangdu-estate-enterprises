# Wangdu's Estate Enterprises

A responsive, single-page property showcase for Wangdu's Estate Enterprises, designed around a modern multi-panel layout inspired by BlaiseWeb. The interface uses a light-blue real estate palette and adapts from desktop to mobile.

## Features

- Responsive navigation that collapses to an accessible mobile menu.
- Property cards and interactive filters for land, subdivisions, houses, hotel/condo, and real estate.
- Founder, company profile, history placeholder, and organizational structure sections.
- A responsive portfolio/activity carousel (three visible on larger screens, one on mobile).
- Inquiry form that opens the visitor's email application with a prefilled message.

## Run locally

Open `index.html` in a browser. Images and web fonts are loaded from external services and require an internet connection.

## Content notes

Property cards are illustrative examples, not verified listings. Availability, location, and pricing are intentionally shared by inquiry. Replace the sample founder, history, contact, and activity copy with confirmed company information before launch. The inquiry form uses `mailto:` and does not submit to a server.
